# Version 0.5 replication package

The file Decision_Rights_v0_5_Publication_Kit.zip is the complete publication kit deposited with the public Zenodo Version 0.5 record. It contains the current manuscript PDF and LaTeX source, editable pre-typesetting source, simulation materials, software evaluation kit, prospective research protocol, synthetic fixtures and outputs, documentation, citations, licensing notices, and its SHA-256 manifest.

The standalone live-pilot software kit is also available as Decision_Rights_Live_Pilot_Engineering_Kit.zip. It includes the software evaluation code, 20 existing fixtures and 80 policy evaluations, software outputs, 13 software unit tests, documentation, and checksums.

- [Zenodo Version 0.5 record](https://zenodo.org/records/24628610)
- [Version DOI](https://doi.org/10.5281/zenodo.24628610)
- [Standalone Version 0.5 manuscript](https://zenodo.org/records/24628610/files/Decision_Rights_in_Human_AI_Organizations_v0_5.pdf?download=1)
- [Concept DOI](https://doi.org/10.5281/zenodo.24584260)

No live LLM experiment or human-participant study is included as a completed result. The protocol and related materials are prospective; all reported outputs are synthetic simulations or software tests.
